# Русификатор The Political Process

Автоматический переводчик, который работает прямо внутри игры. Подходит для любой версии с интерфейсом на NW.js, включая 0.353 и 0.4.

Переводчик ничего не распаковывает и не меняет в файлах игры, кроме одной строки в `index.html`. Он следит за окном игры и подменяет английский текст русским в момент, когда текст появляется на экране. Поэтому новые версии игры переводятся без обновления русификатора.

## Установка

1. Откройте папку игры. В Steam: ПКМ по игре → «Управление» → «Просмотреть локальные файлы». Обычно это `C:\Program Files (x86)\Steam\steamapps\common\The Political Process`. В этой папке лежат `index.html` и `package.json`.
2. Скопируйте туда из архива папку `russifier` и файлы `install-russifier.bat`, `uninstall-russifier.bat`.
3. Запустите `install-russifier.bat`. Он добавит в `index.html` строку подключения и сохранит исходный файл как `index.html.bak-russifier`.
4. Запустите игру.

Если установщик пишет, что нет прав на запись, запустите его через ПКМ → «Запуск от имени администратора».

**После каждого обновления игры в Steam** (или проверки целостности файлов) запускайте `install-russifier.bat` ещё раз: Steam перезаписывает `index.html`. Накопленный перевод при этом сохраняется.

## Клавиши в игре

| Клавиша | Действие |
|---|---|
| F9 | включить или выключить перевод (удобно сверить с оригиналом) |
| Shift+F9 | перечитать `ru.json` и `fixes.json` без перезапуска игры |
| F10 | статистика: сколько строк в словаре и кэше, есть ли ошибки сети |

## Откуда берётся перевод

Для каждой строки на экране русификатор ищет перевод в таком порядке:

1. `russifier/ru.json` — ручной словарь. В нём около 450 терминов: меню, должности, палаты, партии, выборы, бюджет. Эти строки всегда переводятся так, как записано в словаре.
2. `russifier/cache.json` — всё, что уже переведено онлайн. Файл создаётся и пополняется сам.
3. Онлайн-переводчик Google. Если строки нет ни в словаре, ни в кэше, она отправляется на перевод (пачками до 25 строк) и сразу сохраняется в `cache.json`. В следующий раз интернет для неё не нужен.

Пока строка ждёт онлайн-перевода, на экране виден английский оригинал, обычно меньше секунды. В левом нижнем углу в это время показывается «Русификатор: перевожу новые строки…».

Числа не мешают переводу: «Week 3» и «Week 40» — одна и та же строка «Week {0}», переводится один раз.

## Игра продолжает работать

Скрипты игры иногда проверяют надписи на экране: сравнивают текст кнопки или читают выбранный пункт списка. Если просто заменить текст, такие проверки ломаются. Здесь игра видит английский оригинал (`textContent`, `innerText`, `innerHTML`, `value`, `getAttribute`, `select.value` возвращают английский), а игрок видит русский.

Не переводятся поля ввода (имя персонажа и т. п.), `textarea` и элементы, отмеченные в настройке `excludeSelectors`.

## Как улучшить перевод

- **Исправить строку.** Найдите её в `russifier/cache.json`, скопируйте в `russifier/ru.json` и поправьте перевод. В игре нажмите Shift+F9. Словарь всегда важнее кэша.
- **Числа и склонения.** В `ru.json` можно писать шаблоны: `"You have {0} votes": "У вас {0} {0|голос|голоса|голосов}"` даст «1 голос», «22 голоса», «5 голосов». Порядковые (`12th`) подставляются как «12-й».
- **Систематическая ошибка машинного перевода.** Добавьте правило в `russifier/fixes.json`: `{ "from": "Дом представителей", "to": "Палата представителей" }`. `from` — регулярное выражение. Правила применяются только к онлайн-переводу.
- **Полностью ручной перевод.** Включите `"collectMissing": true` в `settings.json`, поиграйте. Все строки, которых нет в словаре, соберутся в `russifier/missing.json` — переведите их и перенесите в `ru.json`.
- **Без интернета.** `"machineTranslation": false` — тогда используются только словарь и кэш.

Готовым `cache.json` можно поделиться: положите его в папку `russifier` на другом компьютере, и там всё будет переведено сразу.

## Настройки (`russifier/settings.json`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | перевод включён при запуске |
| `machineTranslation` | `true` | переводить онлайн строки, которых нет в словаре и кэше |
| `endpoint` | Google gtx | адрес переводчика (`{sl}`, `{tl}`, `{q}` подставляются) |
| `requestDelayMs` | `400` | пауза между запросами |
| `maxBatchItems`, `maxBatchChars` | `25`, `1500` | размер пачки строк в одном запросе |
| `backoffBlockedMs`, `backoffErrorMs` | `60000`, `10000` | пауза, если переводчик ограничил запросы или нет сети; дальше удваивается до 10 минут |
| `gameSeesOriginal` | `true` | игра читает английский оригинал (см. выше); не выключайте без причины |
| `translateCanvas` | `true` | переводить надписи на графиках |
| `translateDialogs` | `true` | переводить системные окна `alert`/`confirm` |
| `showStatus` | `true` | показывать индикатор онлайн-перевода |
| `hotkeyToggle`, `hotkeyStatus` | `F9`, `F10` | горячие клавиши |
| `excludeSelectors` | `[]` | CSS-селекторы элементов, которые нельзя трогать |
| `fontFamily` | `""` | принудительный шрифт, например `"Arial"` |
| `extraCss` | `""` | свой CSS, например уменьшить шрифт в тесных кнопках |
| `collectMissing` | `false` | собирать непереведённые строки в `missing.json` |

## Удаление

Запустите `uninstall-russifier.bat`. Строка подключения уберётся из `index.html`, игра снова будет на английском. Папку `russifier` после этого можно удалить.

## Ограничения

- Онлайн-перевод идёт через бесплатный адрес Google Translate. Это не официальный API: при очень большом числе запросов Google может временно отвечать ошибкой 429. Русификатор тогда ставит паузу и продолжает сам, а уже переведённое работает из кэша. В первые сессии, пока кэш наполняется, нужен интернет.
- Машинный перевод неидеален: встречаются ошибки в согласовании, например «Палата представителей принял» после правила из `fixes.json`. Такие строки лечатся правкой в `ru.json`.
- Если фраза разбита тегами (`You have <b>5</b> votes`), куски переводятся по отдельности, и перевод получается хуже. Шаблон в `ru.json` для таких мест не поможет — только ручная правка каждого куска.
- Русский текст длиннее английского, поэтому в узких кнопках надпись может переноситься. Поправить можно через `extraCss`.
- Русификатор проверен автотестами на макете интерфейса игры в Chromium и в режиме NW.js (Node + DOM), но не на настоящей сборке игры: её файлов при разработке не было. Если какой-то экран ведёт себя странно, нажмите F9: если с выключенным переводом всё работает, добавьте проблемный элемент в `excludeSelectors` и сообщите, какой это был экран.

## Для разработчиков

```
cd tests
npm install
node node.test.js        # режим NW.js: fs, http, кэш, профиль, нет сети
node browser.test.js     # Chromium: DOM, логика игры, canvas, F9, кэш, скорость
PWSH=pwsh bash install.test.sh   # установщик и удаление
```

Архив для игроков собирается скриптом `./build.sh` в `dist/`.
