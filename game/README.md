# КАБИНЕТ — Республика Новария

Политическая стратегия на один файл: `index.html`. Никакой сборки и сервера — откройте файл в браузере.

Вы президент вымышленной Республики Новария. Одиннадцать субъектов, две палаты парламента, четыре оппозиционные фракции и шестнадцать сезонов до выборов. Каждый сезон даёт три действия и ограниченный политический капитал.

## Как запустить

```bash
open game/index.html          # macOS
xdg-open game/index.html      # Linux
```

Интерфейс рассчитан на телефон, но нормально живёт и в широком окне. Шрифты подгружаются с Google Fonts; без сети подставляются системные.

## Что внутри

- **Кабинет** — советник, тема сезона, обещания стране, правительство и действия сезона.
- **Палаты** — состав Народной палаты (500 мест) и Сената (175), законы и голосования.
- **Курс** — две идеологические оси и пять электоральных блоков: рабочие, село, горожане, патриоты, интеллигенция.
- **Карта** — одиннадцать регионов в четырёх режимах: губернаторы, поддержка, напряжённость, экономика.
- **Мир** — соседние страны, договоры и международные программы.
- **Бюджет** — налоги, отрасли, доходы и расходы казны.
- **Летопись** — графики правления и хроника ключевых событий.

Рейтинг не задан сверху: он собирается из настроений блоков, а демография регионов превращает эти настроения в мандаты. Экономика реагирует с задержкой — налоги и законы двигают инвестиции, инвестиции через сезон-другой двигают ВВП, а ВВП уже занятость и налоговую базу.

Проигрыш — дефолт казны или падение одобрения ниже порога. После поражения на выборах игра не кончается: можно возглавить оппозицию и вернуться через шестнадцать сезонов.

## Разработка

Игра — один HTML-файл: стили в `<style>`, вся логика в единственном `<script>` внизу. Состояние живёт в глобальном `S`, экраны собираются функциями `tab*`, диалоги — через очередь `sheet()`.

Проверить синтаксис и прогнать автоматическую партию (нужен Playwright с Chromium):

```bash
node --check <(sed -n '/^<script>$/,/^<\/script>$/p' game/index.html | sed '1d;$d')
```
