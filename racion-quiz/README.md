# Рацион под цель — тест и план питания

Статический квиз без сборки и зависимостей. Человек отвечает на 12–13 вопросов и сразу, без регистрации, получает расчёт калорий и БЖУ, прогноз по весу и меню на день с заменой блюд.

Каталог не связан с навыком `SKILL.md` из корня репозитория и живёт здесь только как отдельный пример.

## Запуск

```sh
cd racion-quiz
python3 -m http.server 8000   # открыть http://localhost:8000
```

Подойдёт любой статический хостинг: нужны только `index.html`, `styles.css`, `app.js` и `dishes.js`.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `app.js` | шаги теста (`STEPS`), расчёт (`computePlan`), сборка меню (`buildMenu`), отрисовка и маршрутизация по `location.hash` |
| `dishes.js` | база блюд: БЖУ, время готовки, тип диеты, аллергены. Калории считаются из БЖУ |
| `styles.css` | светлая и тёмная темы, мобильная вёрстка, печать |

## Как считается

- Базовый обмен: формула Миффлина — Сан-Жеора. Расход: умножение на коэффициент активности 1,2 / 1,375 / 1,55 / 1,725.
- Снижение веса: дефицит до 20% расхода (не больше 750 ккал), но не ниже 1200 ккал для женщин и 1500 для мужчин.
- Набор массы: профицит 10%.
- Белок: 1,4–2,0 г на кг «разумного» веса (для избыточной массы тела берётся вес при ИМТ 25), в пределах 15–35% калорий. Жиры 27% калорий, остальное углеводы.
- Прогноз по весу: 7700 ккал на кг, линейная оценка. В интерфейсе подписан как грубая.

## Ограничения безопасности

План сводится к поддержанию веса, а не к дефициту или профициту, если:

- возраст меньше 18 лет;
- отмечены беременность или кормление, диабет, заболевания ЖКТ, расстройство пищевого поведения;
- ИМТ ниже 18,5 и выбрано снижение веса.

Цель по весу ниже ИМТ 18,5 не принимается.

## Что осознанно не делается

- Нет таймеров «осталось 10 минут», счётчиков «сейчас смотрят 23 человека» и ложной загрузки.
- Нет пейвола и обязательной почты перед результатом.
- Нет аналитики и сторонних скриптов. Ответы лежат только в `localStorage`.

## Настройка

В начале `app.js` в `CONFIG.cta` можно задать кнопку в конце результата (например, запись на консультацию). По умолчанию она скрыта.
